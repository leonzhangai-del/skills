# Arcora Skills

Arcora homepage: https://www.arcora-ai.com/

![Arcora layered architecture for AutoCAD agents](../website/assets/agent-two-foundations-mindmap.svg)

## Overview

This directory contains Arcora skills for AI agents. These skills help agents work with Arcora collaboration sessions and AutoCAD drawing content.

## Available Skills

- [`arcora-cli`](arcora-cli/SKILL.md): Inspect, view, and edit collaborative AutoCAD drawings through the Arcora command-line tool.

## Install

```bash
npx skills add https://github.com/leonzhangai-del/skills --skill arcora-cli
```

Restart your agent client after installation.
